# Library Management System (Java OOP)

## Project Overview
The Library Management System is a console-based Java application developed using Object-Oriented Programming (OOP) principles.  
It allows librarians to manage books and members, search books, and handle borrowing and returning operations efficiently.

## Objectives
- Implement real-world library operations
- Apply OOP concepts such as encapsulation, abstraction, and modular design
- Use Java collections for data management
- Create a menu-driven interactive application

## Technologies Used
- Java (JDK 8+)
- Object-Oriented Programming
- ArrayList Collection
- Console-based UI

## Features
- Add new books
- Register members
- Display all books
- Display available books
- Search books by title, author, or genre
- Borrow and return books

## How to Run the Project
1. Install Java JDK
2. Clone the repository
3. Open the project in VS Code / IntelliJ
4. Compile all files
5. Run `LibrarySystem.java`
